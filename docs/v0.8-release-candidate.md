# v0.8.0 installation and release checks

CPDataKit 0.8.0 combines selective reading, scientific heatmaps, schema drafts, mapping previews,
reproducible batches and the attributed KupferDigital/FE integration example.

## Install and use

Build from this directory and install the wheel into a new Python >=3.12 environment:

```powershell
python -m build --outdir dist/v080
python -m venv .artifacts/candidate-env
.artifacts/candidate-env/Scripts/python.exe -m pip install dist/v080/cpdatakit-0.8.0-py3-none-any.whl
.artifacts/candidate-env/Scripts/python.exe -m pip check
.artifacts/candidate-env/Scripts/cpdatakit.exe --version
.artifacts/candidate-env/Scripts/cpdatakit.exe ui --workspace .artifacts/candidate-workspace --no-browser
```

On Linux/macOS the environment executables are under `bin/`. Use the
[workflow guide](post-v07-workflows.md) for slices, drafts, mappings and batches, or run the
[reference integration](../examples/cpfe-tensile/README.md) from the extracted source distribution.
The wheel contains the library and web assets. The source distribution also contains examples,
tests, reference data and their attribution.

## Verification

[The P0 record](verification/2026-09-08-v080-p0.md) lists exact artifacts, actual environments,
quality results and remaining CI cells. [Dependency notes](v0.8-dependencies.md) explain the
Python-specific lower combinations and the evidence behind the three adjusted runtime floors.

To reproduce one matrix cell with its selected interpreter:

```powershell
python scripts/run_v06_dependency_matrix.py --candidate-set lower --output .artifacts/matrix-lower.json
python scripts/run_v06_dependency_matrix.py --candidate-set latest --output .artifacts/matrix-latest.json
```

Use a new output path for each run. Each command creates a clean environment and retains the
wheel, pip installation report, full test log, coverage, dependency operations and HTTP smoke.

## Release procedure

The [P0 report](verification/2026-09-08-v080-p0.md) and [file inventory](verification/2026-09-08-v080-files.md)
record the local candidate cutoff. The user authorized the v0.8.0 release on 2026-09-08.
The release branch is reviewed through a PR against `koocmitwho/cpdatakit:main`.

The PR runs Windows/Linux/macOS with Python 3.12/3.13 and lower/latest dependencies.
All required checks and the dependency matrix must pass before merge. The `v0.8.0` tag on
the merged commit triggers PyPI Trusted Publishing. The GitHub Release uses the distributions
from that workflow, with their hashes checked against PyPI.

The code, schemas and reference data remain traceable through the release tag. The original
candidate reports retain their verification cutoff and do not substitute for hosted CI.
