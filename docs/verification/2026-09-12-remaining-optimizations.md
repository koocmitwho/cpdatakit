- **846 通过，1 跳过，7 条警告；覆盖率 89.07%，耗时 95.67 秒。**
- 跳过项需要当前 Windows 会话不具备的符号链接创建权限；硬链接别名保护已通过。

## 性能与容量测量

启动测量各运行五个独立进程，表中为中位数，包含进程创建和退出时间。

| 操作 | 优化前 | 最终源码 |
| --- | ---: | ---: |
| `import cpdatakit` | 936.1 ms | 65.1 ms |
| `cpdatakit --version` | 1,313.4 ms | 91.5 ms |
| `cpdatakit --help` | 1,342.0 ms | 93.4 ms |

对 200,000 行、9,390,377 字节输入的验证请求返回 HTTP 200，耗时 1.248 秒。
以 10 ms 间隔探测事件循环，最大观测间隔为 37.0 ms。这是本机一次指定负载的测量，
不等同于所有工作负载的响应上限。

独立 Windows 进程完成 500 个任务，每个任务产生 1,000 次进度更新，共 500,000 次。
超过两个待处理任务的提交被拒绝；回调消费结果后释放状态，最终保留任务数为 0。
日志保持在配置的 32 条、每条 128 字符以内，测量循环耗时 7.359 秒。
工作集由 97.17 MiB 增至 97.99 MiB，增加约 0.82 MiB；tracemalloc 峰值约 426.68 KiB。
该练习使用小型合成结果和校验和接收端，验证配置上限，不代表任意任务的内存保证。
