## 实现范围

| 项目 | 行为与验证边界 |
| --- | --- |
| 数值与单位往返 | 原生整数类型保留；大整数与缺失值在内存中精确保留，混合数组只接受无损类型提升。默认 HDF5 1.0、HDF5 2.0、两个 NetCDF 引擎和 Zarr 的实际写读逐值验证；后端不能无损表示的 object/缺失数据明确拒绝，force/allow_invalid 不能绕过。标准 unit/units/metadata 和坐标单位统一解析，冲突拒绝且不改原对象。 |
| 摘要和比较 | 整数 min/max 保持 Python int；均值和总体标准差按精确比值累加、最后舍入，覆盖 float32/float64 抵消、中间溢出和小残差。整数/浮点比较不提前窄化；差值超出有限浮点范围时明确 unavailable，保留原因与原值。v1 numeric_fields 与单位冲突语义保留。 |
| 任务终态保存 | 完成证据先写入独立文件，再更新目录；有界重试不依赖 HTTP 轮询，待保存状态在 API/页面可见。未保存任务不提前淘汰，容量不足停止接收新工作；重启校验完成证据后回放。 |
| 工作区所有权 | create_app 在创建目录记录或判定旧任务前取得操作系统文件锁；路径别名和同进程第二实例同样受约束。正常关闭等待请求、响应清理和任务写入结束；异常启动清理资源；进程死亡由内核释放锁。 |
| 输出崩溃恢复 | 转换、报告、图表和比较事务在发布前留下阶段、路径、身份和摘要证据。项目恢复入口先只读列出旧输出、新输出和快照；恢复复核项目/路径/摘要并复制到未占用位置，重复操作返回同一结果。损坏、被替换或归属冲突时保留证据。 |

热图切片输出仍沿用其既有发布路径，没有纳入本轮新增事务清单。
本轮覆盖经测试的进程异常退出；文件证据经过 flush/fsync，不据此声称断电一致性。
如果目录数据库和独立完成证据同时无法持久化，内存状态仍可观察，但不能保证进程退出后恢复。

## 三项工程改进

- local-ui 能力检测移除仅用于开发测试的 httpx；独立运行环境没有该包时仍可启动实际服务。
- Zarr inspect 将字节、文件数和符号链接检查合并为一次目录遍历。20 元素、chunk=2
  的合成存储实测由 3 次各 14 项变为 1 次 14 项，数字数组载荷读取仍为 0。
  字节超限提前退出；非 Zarr 路径仍先拒绝字节超限，再检测格式。没有声称耗时提升倍数。
- 新增 `scripts/smoke_browser_installed.py`：浏览器工具环境与 wheel 运行环境分开。
  Chromium 操作自定义 schema、上传、验证、转换、JSON 报告、下载，然后在运行环境
  重新读取 HDF5 并逐值核验；另验证越界路径的可见错误和实际目标未生成。
  以页面状态/响应/下载事件等待，保留截图、页面、trace、控制台和服务器日志。
  CI 增加独立 wheel 浏览器任务及失败证据上传；未推送，因此没有远端运行通过的结论。
