## Selective-read baseline

Input seed: 20260907. Three `float32(128,512,512)` arrays contain 402,653,184 bytes (384 MiB).
Storage chunks are `(4,128,128)`. The Parquet input has 2,000,000 rows, 8 float64 columns,
and 65,536-row groups. Scientific reads select one variable and one time step, Parquet reads
one column and 100 rows. Each method runs in a fresh process, alternating order over three repeats.

| Format | Eager median seconds | Selected median seconds | Eager median peak RSS MiB | Selected median peak RSS MiB |
| --- | ---: | ---: | ---: | ---: |
| NetCDF | 0.168702 | 0.018482 | 510.500 | 119.273 |
| Zarr 3 | 0.638004 | 0.174197 | 511.406 | 126.500 |
| Parquet | 0.025775 | 0.005186 | 179.531 | 117.000 |

All selected-value digests matched the corresponding eager result. Elapsed time excludes
imports, while process peak RSS includes imports. OS caching was uncontrolled. These are local
measurements, not a cross-platform performance guarantee. Full measurements, physical file sizes
and package versions are in [the benchmark JSON](2026-09-07-selective-benchmark.json).

Reproduce with a fresh empty directory:

```bash
python scripts/benchmark_selective_read.py --output-dir .artifacts/selective-baseline --time 128 --side 512 --rows 2000000 --repeats 3
```

## Build procedure and remaining limits

Packaging verification passed: both distribution files matched byte for byte across two builds,
Twine and metadata checks passed, and a clean wheel install passed `pip check`. The installed
package was loaded from the separate `wheel-env` site-packages directory. Legacy validate, convert
and plot commands and the new draft, slice, batch and tensile integration services passed.
Uvicorn returned HTTP 200 for `/health`, `/`, and all four bundled JS/CSS assets.

The final browser run had zero console errors or warnings, displayed the image without page
overflow, and downloaded the PNG. Captures are `thermal-final-desktop.png` and
`thermal-final-mobile.png` in `output/playwright/`.

Packaging verification uses a fixed `SOURCE_DATE_EPOCH` from the baseline commit, two wheel/sdist
builds, `check_reproducible_build.py`, `check_release.py --dist-dir`, Twine and a separate clean
wheel environment. Local logs and package artifacts are under `.artifacts/`. These are development
builds carrying the unchanged version metadata, not release artifacts to upload.

Selected reads return eager arrays. Preview checks both encoded input bytes and estimated decoded
numeric array bytes, and rejects variable-length scientific arrays when a safe bound is unavailable.
Cooperative cancellation takes effect between checkpoints. Current backend calls and full validation
cannot be forcibly interrupted. Workbench conversions stage output and serialize promotion,
registration and rollback in one process. A filesystem failure during rollback retains its backup.
This is not a multi-process transactional filesystem service.

Mesh topology and schema migration remain separate milestones with explicit prerequisites in
[the roadmap](../roadmap.md).

Verification cutoff: production code was unchanged after the 550-test complete run. Only the guides, this
verification record and the execution-plan checkboxes were finalized after packaging.
