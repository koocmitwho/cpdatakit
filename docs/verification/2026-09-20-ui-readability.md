## 范围

- 工作台按准备数据、检查与处理、查看结果组织；中文主文案，保留字段和单位原名。
- 显示当前文件与规则，校验结果绑定提交时的选择；切换后明确提示历史结果。

- 输出冲突指出路径并聚焦输入框，不自动勾选覆盖；成功任务按明确产物 ID 提供链接。

  JSON/Markdown 契约、数值计算与数据转换语义保持原有行为。
