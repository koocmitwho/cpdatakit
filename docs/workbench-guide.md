# 中文工作台与数据报告

本页对应当前尚未发布的开发版界面。PyPI 0.8.1 的按钮仍可能使用英文；
这里描述的是当前源码中的操作方式。

启动 `cpdatakit ui --workspace ./cpdatakit-workspace`，创建或打开一个项目。
文件、规则、任务记录和结果保存在所选本地工作区。

## 1. 准备数据与规则

在“数据规则（Schema）”中选择数据适用的规则。规则声明字段名称、类型、单位和维度，
不是对科学结论的判断。表格可使用内置曲线、采样点、二维场规则，也可展开
“添加自定义规则”上传独立 JSON；多维数组使用 schema 2.0。

选择文件并点击“上传并检查”。支持 CSV、JSON、CPDataKit HDF5、NetCDF、Parquet，
Zarr 使用单独的目录上传入口。页面显示当前数据和规则，上传后可继续校验。

“高级设置”保留规则草案和字段映射功能。确认草案中的单位与物理角色后再保存。
映射只在转换操作中应用，校验和报告始终检查所选上传文件本身。

## 2. 检查与处理

选择已上传的数据，点击“校验数据”，查看本次文件、规则、错误和警告。
切换文件或规则后，之前的校验结论会标为历史结果；重新校验当前选择。

- **生成报告**：选择 HTML、Markdown 或 JSON，填写项目内保存路径，点击“生成报告”。
- **转换并保存**：选择目标格式和项目内路径；需要单位转换或字段改名时，先预览映射。
- **二维切片**：在高级查看中选择至少有两个维度的数值变量，一维曲线不使用此工具。

已有同名文件时，页面会指出输出路径。可以修改文件名另存；确实需要替换时，明确勾选
“我确认替换”后重新提交。仅更换数据或规则，不会替你改写已有结果。

任务成功后可直接查看或下载结果。“结果等待保存”表示任务计算已经完成，但目录记录
仍待持久化，不能把它当作已经可靠保存的终态。中断恢复入口位于任务记录旁。

## 3. 查看结果

“查看与下载结果”集中列出结果文件；任务记录单独显示处理中、已完成、失败和取消状态。
历史记录按需加载。转换文件如果要用于后续页面校验或报告，需要把该文件作为新的输入上传。

HTML 报告可离线打开与打印。顶部显示文件、规则和校验概览，下方列出字段、数值统计、
问题与来源摘要。未提供的统计量标记为未提供，未声明的单位不会自动当作无量纲。
完整元数据保留在可展开的详细记录中。JSON 与 Markdown 报告仍沿用原有结构。

## 拉伸案例的第一步

按 [KupferDigital 案例](../examples/cpfe-tensile/README.md) 生成 `experiments.h5` 和
`experiments.schema.json`，先上传规则，再上传数据。选择
`kupfer-tensile-measured-derived` 后运行校验，预期 `record = 483`。

这份数据含 H_08、H_16、H_18 三个样品，各 161 点。工程应变窗口为 0–0.008，
名义应力增量单位为 MPa。报告展示已有数据的结构和统计，不重新运行求解器，也不新增物理验证结论。
