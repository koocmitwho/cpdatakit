# Post-v0.7 development plan

The six stages below implement the scope authorized in this task. Work starts at
`d8ae767e14212cb6daa1932531695da94420cb64` (origin/main, checked 2026-09-07), in
`cpdatakit-next`, branch `codex/post-v07`. The original checkout and v0.7.0
release directory are preserved. Stage names do not authorize a release.

Architecture: format readers own selection; application services own validation,
mapping, plotting and conversion; CLI and HTTP call those services. New workflows
retain input identity and explicit scientific declarations. Python >=3.12 and
the v0.5/v0.7 compatibility contracts remain in force. No new runtime dependency
is planned. Tests precede implementation; each stage records its red/green checks.

- [x] **1 / v0.7.1 — Selective I/O and job completion.** Extend `Selection` with
  named dimension ranges while preserving positional fields/start/stop semantics.
  Share lazy xarray selection between NetCDF and Zarr; read only overlapping
  Parquet row groups, materializing bounded batches. Test excluded data is never
  loaded, coordinates/metadata survive, bounds and empty selections, legacy
  pandas indexes. Add subprocess benchmark against eager v0.7 behavior with
  deterministic input, environment, file size, elapsed time and peak RSS. Reproduce
  cancellation around output completion; define explicit checkpoints and retain
  committed results in both job and catalog records.
- [x] **2 / v0.8 — A temperature field viewer.** Add a shared slice service for
  `temperature(time,y,x)` using selection before materialization. Return variables,
  dimensions, coordinates and units for controls. Plot two explicitly selected
  axes, fixed indices for all others, and optional color limits. Record variable,
  units, slice indices/coordinate values in the plot and result metadata. Add
  HTTP/UI controls, PNG export and desktop/narrow-screen browser acceptance.
- [x] **3 — Research integration.** Read the released experiment-to-CPFE source,
  license and verification artifacts; add a CPDataKit example/adapter that audits
  experimental and extracted/training arrays with fields, units, dimensions,
  sources and hashes. Reuse existing verified values, preserve the 0–0.8% scope,
  and distinguish this owned-repository integration from independent adoption.
- [x] **4 — Schema drafts and mapping preview.** Draft editable contracts from
  observed structure, retaining unresolved unit/role/definition questions outside
  the executable schema. Preview normalization through the existing mapping and
  validation services, including before/after values, units and dimensions. Add
  API, CLI and workbench entrypoints; schema 2 dimension mapping uses the same
  rules in preview and conversion.
- [x] **5 — Reproducible batches.** Add JSON configuration and a batch application
  service/CLI declaring input, schema, mapping and output per item or shared
  defaults. Preflight output collisions and protected inputs; continue across
  per-file failures. Save atomic manifests with config/source/output hashes,
  parameters and validation. Retry skips only verified successful outputs from
  the same effective configuration; existing single-file defaults stay intact.
- [x] **6 — Documentation and final verification.** Update quickstart, examples,
  development changelog and roadmap. Synchronize only the authorized GitHub About
  description and Issue #6 scope. Specify deferred mesh topology and schema
  migration acceptance prerequisites. Run full pytest/coverage (>=85%), Ruff,
  release metadata checks, reproducible wheel+sdist, clean install/CLI/Uvicorn
  smoke and real browser acceptance. Record exact local platform and remaining
  limits. Leave all implementation uncommitted and unpublished.
